{% load i18n admin_urls static %}{% comment %} Crystal "size cards" inline — a Shopify-style variant grid for ProductVariant. The scaffold (wrapper classes/ids, management form, per-card ids, the trailing empty-form card, pk/fk hidden fields) is copied from jazzmin/templates/admin/edit_inline/stacked.html because django/contrib/admin/static/admin/js/inlines.js binds to it literally: it reads data-inline-type="stacked", selects "#-group .inline-related", clones "#-empty" and rewrites ids matching "-(\d+|__prefix__)". Change any of that and "Add another size" dies with no error. Only the body that renders the fields is Crystal's own. Fields are rendered by iterating form.visible_fields rather than by hard-coded name, so a card never drops a field the ModelAdmin adds later and never renders one the form does not have. `name` is lifted into the card head, DELETE is rendered explicitly at the foot of the body, and the hidden pk/fk close the card. {% endcomment %}
