How it works

  • The first row is the header. Column names are matched ignoring case; unknown columns are ignored.
  • sku identifies the product — an existing SKU is updated in place, a new one is created. Nothing is ever duplicated.
  • Blank cells leave the existing value alone, so re-uploading the same file changes nothing.
  • tags and gallery take several values separated by commas or pipes.
  • features is one Title | detail per line (or icon | Title | detail, as on the product edit screen).
  • hero, gallery and video hold a path or link (e.g. product-photos/LI001A/hero.webp) — not an uploaded file.
  • Brands and categories must already exist; a row naming an unknown one is reported instead of inventing it.
  • A bad row never stops the import — the good rows still go in.
